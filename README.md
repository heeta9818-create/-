# 도배 견적 계산기

방 크기를 입력하면 필요한 벽지 롤 수와 예상 견적이 바로 나오는 웹앱입니다.

## 기술 구성 (일부러 최소화)

빌드 에러를 줄이기 위해 꼭 필요한 것만 씁니다.

- Next.js 15 (App Router)
- React 19
- 일반 JavaScript + 일반 CSS

Tailwind, TypeScript, 데이터베이스, 로그인 없음 → 빌드가 실패할 구멍이 거의 없습니다.

## 내 컴퓨터에서 실행하기

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 접속.

## 배포 전 확인 (중요)

Vercel에 올리기 전에 반드시 아래를 먼저 돌려보세요.
여기서 통과하면 Vercel에서도 거의 통과합니다.

```bash
npm run build
```

`✓ Compiled successfully` 가 나오면 정상입니다.

## Vercel 배포 순서

1. https://vercel.com 로그인 (GitHub 계정으로)
2. **Add New → Project**
3. 이 저장소를 **Import**
4. 설정은 **아무것도 건드리지 않습니다**
   - Framework Preset: `Next.js` (자동 인식)
   - Root Directory: `./`
   - Build Command / Output Directory: 비워둔 채로 (자동)
   - Environment Variables: 없음
5. **Deploy** 클릭

## 계산 방식

- 벽 둘레 = 2 × (가로 + 세로)
- 필요 폭수 = 벽 둘레 ÷ 벽지 폭 (올림)
- 1롤당 폭수 = 롤 길이 ÷ (천장 높이 + 10cm 재단 여유) (내림)
- 필요 롤 수 = 필요 폭수 ÷ 1롤당 폭수 (올림)

| 벽지 | 폭 | 1롤 길이 |
|---|---|---|
| 실크벽지 | 106cm | 15.6m |
| 합지벽지 | 93cm | 17.5m |

문·창문 공제, 몰딩, 벽면 상태 등 현장 조건은 반영되지 않습니다.
실제 견적은 현장 확인 후 달라질 수 있습니다.

## 요금제 (무료 / 프로)

### 사장님이 직접 채우셔야 하는 곳

| 파일 | 무엇을 |
|---|---|
| `app/lib/plan.js` | **가격**(`PRO_PRICE`, `PRO_PRICE_YEAR`), 무료 저장 건수, 기능표 |
| `app/lib/compare.js` | 다른 서비스와의 비교 내용 |

### compare.js 를 채울 때 반드시 지킬 것

다른 업체의 **요금·수수료·기능은 직접 확인한 사실만** 적으세요.
확인하지 않은 내용을 적으면 표시광고법상 부당한 비교광고가 될 수 있습니다.

각 항목의 `verify` 칸을 비워두면 화면에도 나오지 않습니다.
채울 때는 확인 시점을 같이 적어두면 안전합니다.

```js
verify: "○○의 수수료는 건당 ○○원입니다 (2026년 3월 직접 확인)",
```

### 무료 제한이 걸리는 지점

- 견적 저장 `FREE_SAVE_LIMIT`건까지 (`app/lib/plan.js`)
- 견적서 하단에 무료판 문구 한 줄

### 아직 없는 것

**결제가 붙어 있지 않습니다.** 지금은 요금제 페이지의 버튼으로 프로를 켜고 끌 수 있을 뿐입니다.

실제로 돈을 받으려면 아래가 필요합니다.

1. 사업자등록
2. 결제대행사(PG) 계약 — 포트원, 토스페이먼츠 등
3. 계정(로그인) + 서버 — 누가 결제했는지 서버가 알아야 합니다

지금은 요금제 정보가 **브라우저 안에만** 있어서, 마음먹으면 우회할 수 있습니다.
반응을 보는 용도로는 충분하지만, 과금 방어는 되지 않습니다.

## 레이저 측정기 연결 (브랜드 무관)

`app/lib/meter.js`

### 되는 곳 / 안 되는 곳

| 환경 | 됨? |
|---|---|
| 안드로이드 크롬 | ✅ |
| PC 크롬 · 엣지 | ✅ |
| **아이폰 (사파리·크롬 모두)** | ❌ |

애플이 사파리에 Web Bluetooth를 넣지 않았습니다. 아이폰 크롬도 속이 사파리라 같습니다.
지원하지 않는 기기에서는 **버튼 자체가 나타나지 않습니다.**

### 어떻게 브랜드를 안 가리나

특정 기기를 정해두지 않습니다. 붙은 기기가 내보내는 신호를 **전부 열어놓고**,
방 치수로 말이 되는 숫자(5cm~200m)가 나오는 자리를 찾아 기억합니다.

읽는 방식은 7가지를 순서대로 시도합니다.

| 순서 | 방식 | 흔한 곳 |
|---|---|---|
| 1 | 글자 (미터 / cm / mm) | 시리얼 방식 저가 모듈 |
| 2 | 소수 4바이트 | 라이카 디스토 |
| 3 | 정수 4바이트 mm | 국산·중국산 다수 |
| 4 | 소수 4바이트 (역순) | 드물게 |
| 5 | 정수 2바이트 mm | 짧은 신호만 보내는 기기 |

한 번 찾은 기기는 **이름으로 기억**해서 다음부터 바로 붙습니다.
값이 이상하면 `값이 이상해요` 버튼으로 기억을 지우고 다시 찾습니다.

### 그래도 안 되는 것

`SERVICES` 목록에 없는 규격은 **브라우저가 열람 자체를 막습니다.**
그럴 땐 연결 실패 메시지에 기기 이름이 나오니, 그 내용으로 목록에 추가해야 합니다.

**아직 실제 기기로 확인하지 못했습니다.** 이 코드를 쓴 환경에는 측정기도 블루투스도 없습니다.

### 쓰는 순서

1. 측정기 전원과 블루투스를 켠다
2. 앱에서 `연결하기` → 기기 목록에서 고른다
3. 방 카드의 `조준` 줄에서 채울 칸을 누른다
4. 측정기 버튼을 누르면 그 칸에 값이 들어가고 다음 칸으로 넘어간다
   (가로 → 세로 → 천장고 → 천장 가로 → 천장 세로)

### 팔기 전 반드시 할 것

**처음 몇 번은 줄자로 잰 값과 대조하세요.** 값이 미터가 아닌 다른 단위로 오거나
소수점이 어긋날 수 있습니다. 5cm~200m 밖의 값은 무시하도록 막아뒀지만,
그 안에서 틀린 값은 걸러지지 않습니다.

## 메모장 붙여넣기

`app/lib/parse.js`

메모장에 적어둔 실측을 그대로 붙여넣으면 방 목록이 만들어집니다.

```
안방 3.6 x 3.0 x 2.4      → 안방 3.6×3×2.4 천장포함 실크
작은방 3.2*2.7            → 천장고는 2.4로 채움
거실 5m 4m 2.4m           → 단위 그대로
주방 280 240 천장제외      → 100 넘으면 cm (2.8×2.4)
침실 3600 3000 2400       → 1000 넘으면 mm (3.6×3×2.4)
창고 3 2.5 합지            → 합지로
서재 4 3 2.4 4.4 3.4      → 뒤 두 개는 천장 가로·세로
드릴 챙기기                → 숫자 없으면 그냥 넘어감
```

- 구분자: 띄어쓰기 `x` `*` `×` `/` `,` `·` 모두 됨
- `천장제외` `천장없음` `벽만` → 천장 끔
- `합지` → 합지벽지, 없으면 실크
### 붙여넣으면 끝

버튼을 따로 누르지 않습니다. 텍스트를 넣는 순간 방 목록이 만들어지고
**바로 아래에 견적 금액이 나옵니다.** 잘못 붙여넣었으면
`붙여넣기 전으로 되돌리기`로 원래 방 목록이 돌아옵니다.

### 천장 — `천`으로 줄여 써도 됩니다

현장에서 쓰는 줄임말을 그대로 알아듣습니다.

| 메모에 적은 말 | 결과 |
|---|---|
| (아무것도 안 적음) | 벽 + 천장 |
| `천` `천장` `천포함` `천장포함` | 벽 + 천장 |
| `천제외` `천X` `천 제외` `무천` `천장제외` `벽만` | 벽만 |
| `천만` `천장만` `천장도배만` | **천장만** (벽 계산 안 함) |

숫자를 5개 적으면 뒤 두 개가 천장 가로·세로입니다. (`서재 4 3 2.4 4.4 3.4`)

방 카드의 `벽` `천장` 칩으로도 켜고 끌 수 있습니다.

## 견적 공유

견적서 화면의 `공유하기` 버튼.

누르면 보낼 방법을 고르는 목록이 펼쳐집니다.

**파일로 보내기**
- **PDF로 보내기** — 견적서 화면 그대로 A4 PDF
- **사진으로 보내기** — PNG. 카톡에서 열지 않아도 바로 펼쳐 보입니다

**글자로 보내기**
- 휴대폰 공유창 (카톡·문자·인스타 목록)
- 문자로 보내기 (`sms:` 링크 — 안드로이드·아이폰 형식을 나눠서 씁니다)
- 내용 복사하기 / 견적 글 전체 보여주기

### PDF는 어떻게 만드나

`app/lib/sheetfile.js`

1. `html2canvas`로 견적서 화면을 그대로 찍는다 (2배 해상도)
2. JPEG로 뽑는다
3. **그 JPEG 한 장을 담은 PDF를 손으로 짠다** (A4 폭, 비율 유지)
4. `navigator.share({files})`로 공유창에 넘긴다. 안 되면 내려받는다

PDF 라이브러리를 안 씁니다. 한글을 글자로 넣으려면 한글 글꼴 수 MB를 통째로
집어넣어야 해서 무겁고 잘 깨집니다. 화면에 이미 제대로 그려진 것을 찍는 편이 확실합니다.

`html2canvas`는 **PDF·사진 버튼을 누를 때만** 불러옵니다 (별도 청크 194KB).
첫 화면 로딩에는 안 실립니다.

### 글자 그대로인 PDF가 필요하면

`PDF로 저장`(인쇄) 버튼을 쓰세요. 브라우저가 만드는 PDF라 글자를 복사·검색할 수 있습니다.
대신 폰에 저장된 뒤 직접 첨부해야 합니다.

### 공유창이 안 뜨는 경우

- **카톡·인스타 등에서 링크를 연 경우** — 그 앱 안의 브라우저에는 공유 기능이 없는 경우가 많습니다.
  크롬으로 열거나, 홈 화면에 추가해서 쓰면 해결됩니다.
- **PC 브라우저** — 공유창이 없습니다. 복사해서 쓰세요.

복사는 두 가지 방법을 다 준비해 뒀습니다. 최신 방식(`navigator.clipboard`)이 막혀 있으면
옛날 방식(`execCommand`)으로 넘어가고, 그것도 막히면 글을 직접 긁을 수 있게 보여줍니다.

### 카카오톡으로 바로 쏘기

카카오 개발자 키가 있어야 합니다(개발자 등록 + JavaScript 키 + 도메인 등록).
지금은 붙어 있지 않아서, 공유창이나 복사를 거쳐야 합니다.

## 고객에게 전달하기

### 연락처에서 고르기

`현장` 카드의 `연락처에서` 버튼. 폰 연락처 목록이 뜨고, **고른 한 명만** 이름·번호가 들어옵니다.

- 앱이 연락처를 통째로 가져가지 않습니다. 브라우저가 허용하지 않습니다
- **안드로이드 크롬에서만** 버튼이 보입니다 (아이폰 미지원)
- 안 보이면 번호를 직접 적으시면 됩니다

### 통화목록은 불가능합니다

웹에는 통화기록을 읽는 방법이 아예 없습니다.
앱으로 만들어도 안드로이드 정책상 통화기록 권한은 기본 전화앱에만 줍니다.

**앱이 대신 문자를 발송하는 것도 불가능합니다.** 어떤 웹앱도 그렇게 못 합니다.
문자 앱이 받는 사람과 내용까지 채워진 채로 열리고, 보내기는 사람이 누릅니다.

### 견적서 링크 (`app/lib/link.js`, `app/q/`)

파일을 내려받게 하는 대신 **링크**를 보냅니다. 받은 사람이 누르면 브라우저에서 바로 펼쳐집니다.

- 견적 전체를 주소의 `#` 뒤에 담습니다. **서버에 저장하지 않습니다**
- `#` 뒤는 브라우저가 서버로 보내지 않으므로 고객 견적이 남의 서버를 거치지 않습니다
- `CompressionStream`으로 눌러 담습니다. **방 8개 기준 주소 315자** — 문자에도 들어갑니다
- 받는 쪽 화면 아래에 `업체에 전화하기` 버튼이 붙습니다

### 보내기 버튼을 누르면

| | |
|---|---|
| **○○님께 문자 보내기** | 연락처를 골랐을 때만. 번호와 내용이 채워진 문자 앱이 열립니다 |
| **견적서 링크 보내기** | 공유창(카톡·문자)에서 고르기. 눌러서 바로 열립니다 |
| 사진으로 보내기 | 카톡 대화창에서 바로 펼쳐 보입니다 |
| PDF로 보내기 | 문서 파일. 받는 쪽에서 열어야 합니다 |
| 견적 링크만 복사 / 내용 글자로 복사 | |
